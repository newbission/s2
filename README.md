# S² — Secret is Secret

> S3가 파일 저장소라면, S2는 시크릿 저장소.

팀이 `.env`와 키파일(`.pem`, `.p12`, 서비스 계정 `json` 등)을 슬랙·DM으로 주고받는 대신,
**권한 있는 사람만 조회·수정할 수 있게** 관리하는 웹 시크릿 매니저입니다.

> **상태: 개발 중 (프로토타입 단계)**. 아래는 목표 설계이며 아직 구현되지 않은 부분이 있습니다.

## 무엇을 하나

- **프로젝트 단위 권한**: 레포 하나 = 프로젝트 하나. `read`(값 열람·다운로드) / `update` / `delete`를 멤버별로 부여하고, 파일마다 예외를 둘 수 있음
- **제한 파일**: 명단에 있는 사람만 열 수 있는 파일. 전용 키로 잠겨 명단 밖에서는 DB를 가져가도 못 엶
- **`.env`와 일반 파일 관리**: `.env`는 원문 그대로(주석·순서 보존) 보관하고 key-value로도 편집. 키파일·JSON·YAML 등은 바이트 그대로 보관하고, 텍스트면 형식에 맞춰 보고 편집
- **버전 이력과 롤백**: 수정할 때마다 새 버전이 쌓이고(파일당 20개), 동시 수정은 낙관적 락으로 막음
- **휴지통**: 지운 파일·프로젝트는 7일 동안 되살릴 수 있음
- **감사 로그**: 누가 언제 무엇을 열람·수정했는지 추가 전용으로 기록

## 보안 설계 요약

- **운영자도 열어볼 수 없음 (E2EE)**: 암호화·복호화는 브라우저에서만. 서버에는 암호문과 잠긴 키뿐이라 DB와 서버 환경변수를 모두 가져가도 시크릿을 복원할 수 없음
- **비밀번호 없는 접속 코드**: 가입할 때 브라우저가 12단어 시드와 128bit 접속 코드를 만들어 한 번만 보여줌. 메일로 보내지 않고, 서버는 원문을 받지 않음
- **상자 승인**: 새 멤버·복구한 멤버는 관리자가 승인해야 데이터를 열 수 있음. 운영자가 속아 계정을 복구해줘도 데이터는 안 열림
- **코드 공개 전제**: 이 저장소가 공개되어도 안전하도록, 보안이 코드 비공개에 의존하지 않음

## 스택

- Next.js (App Router) on Vercel
- Neon Postgres
- 운영 비용 0원 (무료 플랜만 사용)

## 개발 환경

Docker Desktop만 있으면 어느 기기에서든 같은 환경(Node 24 + pnpm)으로 뜹니다.

```sh
docker compose up            # http://localhost:34747 (DB 없이 메모리 목업으로 동작)
docker compose exec app pnpm lint
docker compose down          # 멈춤 (볼륨의 패키지·캐시는 유지)
```

- 소스는 맥 폴더와 공유하고, `node_modules`·`.next`는 Docker 볼륨에 따로 둡니다.
- 포트는 다른 프로젝트와 겹치지 않게 앱 `34747`, DB `54747`입니다. 겹치면 `S2_APP_PORT=34800 docker compose up`처럼 바꿉니다.
- 로컬 Postgres까지 띄우기 (실제 DB 구현 단계용): `docker compose -f compose.yaml -f compose.db.yaml up`
