# S² — Secret is Secret

> S3가 파일 저장소라면, S2는 시크릿 저장소.

팀이 `.env`와 키파일(`.pem`, `.p12`, 서비스 계정 `json` 등)을 슬랙·DM으로 주고받는 대신,
**권한 있는 사람만 조회·수정할 수 있게** 관리하는 웹 시크릿 매니저입니다.

> **상태: 개발 중 (프로토타입 단계)**. 아래는 목표 설계이며 아직 구현되지 않은 부분이 있습니다.

## 무엇을 하나

- **프로젝트 단위 권한**: 레포 하나 = 프로젝트 하나. 키 목록 보기(`read`)와 값 열람(`reveal`)을 분리해 멤버별로 부여
- **`.env`와 키파일 관리**: `.env`는 원문 그대로(주석·순서 보존) 보관하고 key-value로도 편집. 키파일은 바이트 그대로 보관
- **버전 이력과 롤백**: 수정할 때마다 새 버전이 쌓이고, 동시 수정은 낙관적 락으로 막음
- **감사 로그**: 누가 언제 어떤 값을 열람·수정했는지 추가 전용으로 기록

## 보안 설계 요약

- **봉투 암호화**: 데이터마다 DEK(AES-256-GCM)로 암호화하고, DEK는 마스터 키로 감싸 저장. 마스터 키는 DB와 분리 → DB만 유출되면 암호문뿐
- **비밀번호 없는 접근 키**: 사용자별 랜덤 256bit 키를 메일로만 발송, 서버에는 해시만 저장
- **코드 공개 전제**: 이 저장소가 공개되어도 안전하도록, 보안이 코드 비공개에 의존하지 않음

## 스택

- Next.js (App Router) on Vercel
- Neon Postgres
- 운영 비용 0원 (무료 플랜만 사용)
